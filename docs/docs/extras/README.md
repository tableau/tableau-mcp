# Extras

Extra packaging and deployment options beyond the usual npm, source, and Docker getting-started
paths.

In this section:

- [Docker](docker.md): Tableau MCP as a Docker container.
- [Node.js Single Executable Applications](node-sea.md): Package Tableau MCP as a single Windows or Linux executable so users do not need Node.js.
- [Deploy to Heroku](deploy-heroku.md): Experimental one-click Heroku deployment of Tableau MCP.
