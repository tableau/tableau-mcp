# Get %product_name% Capabilities

{/* availability */}
<span className="toolAvailability">Available November 2026 and later.</span>

Return the External Client API capability matrix: for each operation id, whether it requires a Tableau Server connection (requiresServer).

## APIs called

Talks to the running %product_name% instance through the External Client API.

- Return the External Client API capability matrix: for each operation id, whether it requires a Tableau Server connection (requiresServer).

## Optional arguments

### `session`

Session ID; optional if pinned or unique.
