# Get workbook extensions

{/* availability */}
<span className="toolAvailability">Available November 2026 and later.</span>
{/* /availability */}

Lists viz and dashboard extensions in the open workbook. Reload one with its sheet id.

## APIs called

Talks to the open %product_name% workbook through the External Client API.

- Lists viz and dashboard extensions in the open workbook.

## Optional arguments

### `session`

Session ID; optional if pinned or unique.
