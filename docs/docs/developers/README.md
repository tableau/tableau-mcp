# Developers

Information for developers working on or using the Tableau MCP project, including building from
source, testing, debugging, contributing, and using development tools.

In this section:

- [MCP Inspector](mcp-inspector.md): Explore Tableau MCP tools and confirm your configuration is correct.
- [Contributing](contributing.md): Fork-and-pull contribution model and how to onboard a Tableau API as an MCP tool.
- [Debugging](debugging.md): Debug the server over HTTP or stdio from VS Code / Cursor.
- [Unit Tests](unit-tests.md): Run and debug Vitest unit tests colocated with source.
- [E2E Tests](e2e-tests.md): End-to-end tests against a live Tableau site (CI or the mcp-test site).
- [Eval Tests](eval-tests.md): LLM-scored evaluations of whether the model picks the right tools and answers well.
- [Feature Flags](feature-flags.md): Control available features during development via `features.json` or a cloud provider.
