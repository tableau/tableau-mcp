# Configuration

Some configuration is required to both Tableau and Tableau MCP to get the most out of the products.

In this section:

- [Configuring Tableau](tableau-config.md): Tableau platform prerequisites (VDS, Metadata API, Pulse) that MCP tools depend on.
- [Configuring Tableau MCP](mcp-config/README.md): Environment variables, authentication, site settings, and other MCP server configuration.
